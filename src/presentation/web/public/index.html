Trạng thái Runtime
[1] Creational: Builder Sẵn sàng

Dựng đơn hàng từng bước, gom nhóm SKU & chặn bán vượt tồn kho (Overselling).

[2] Structural: Decorator Sẵn sàng

Bọc động BaseOrderPricing với GiftWrap & ShippingInsurance tại runtime.

[3] Behavioral: Strategy Sẵn sàng

Hoán đổi linh hoạt thuật toán chiết khấu (VIP / Khuyến mãi bậc / Thông thường).

[4,5] Factory Method + Adapter Sẵn sàng

Factory khởi tạo Adapter phụ thuộc Port (DIP), SDK ngoài thực thi giao dịch.

[6] Behavioral: Observer Sẵn sàng

Phát sự kiện ORDER_PAID tới Inventory, Email, SMS với cơ chế Fault-Tolerant.
